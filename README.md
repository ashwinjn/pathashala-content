# पाठशाला — content

This repository holds everything the **Pāṭhaśālā** Sanskrit app teaches: ślokas, stories, words, sentences, dialogues and roots. All of it lives in one file, **`content.json`**.

When the app opens with internet, it reads this file. If the `version` number here is higher than what the phone has, the phone downloads the new content and keeps it for offline use. You don't need to reinstall anything.

## Where the content comes from

| Part | Source | Reliability |
|---|---|---|
| Verb tables (75 roots) and noun/pronoun tables (21) | Generated by **Vidyut**, a Pāṇinian rule engine from the Ambuda project (MIT licence) | High: rule-based |
| Ślokas marked "Source text" | Bhartṛhari's Nītiśataka and Kulaśekhara's Mukundamālā, from GRETIL via Ambuda (CC BY-NC-SA 4.0) | Authentic text |
| Ślokas marked "Checked" | Compared against a published text | Text checked |
| 49 stories marked "class notes" | Sanskrit + English from the class notes *Short Sanskrit Stories, Part 2*, transcribed by OCR and checked word by word | Teacher-written; transcription may still contain a few slips |
| Tap-a-word notes on class-notes stories (`AUTO_G`) | Grammar from the Vidyut lexicon; meanings added separately | Grammar reliable; meanings unverified |
| Everything else: translations, Kannada, simplified stories, dialogues, sentences, word glosses | Written for this app | ⚠️ **Not yet checked by a Sanskrit teacher** |

## How to make a change (from your phone or computer)

1. Open **`content.json`** on GitHub and tap the ✏️ pencil (Edit).
2. Make your change (examples below).
3. **Raise the `version` number by 1** at the top, e.g. `"version": 1` → `"version": 2`. If you skip this, phones won't pick up the change.
4. Optionally update `"updated"` (the date) and `"notes"`. The notes are shown in the app's Settings as "what's new".
5. Tap **Commit changes**.
6. Open the **Actions** tab. A ✓ green tick means the file is fine; a ✗ red cross means there's a mistake. The message tells you which item and what's wrong. Fix it and commit again.

Phones get the update the next time the app is opened with internet. GitHub can take up to ~5 minutes to serve the new file. In the app, Settings → **Check for new content** forces a check.

**If you make a mistake:** the app checks every download, so a broken file is ignored and the phone keeps its last good content. Nothing breaks.

## Examples

Each section is a list in square brackets `[ … ]`. Items are separated by commas. Add a new item at the end, and put a comma after the item before it.

### Add a word — `WORDS`
```json
{"sa": "आम्रम्", "en": "mango", "kn": "ಮಾವಿನ ಹಣ್ಣು"}
```
To put it in a synonym family, add `"c": "sun"`, using one of the family names listed in `CLUSTERS`.

### Add a śloka — `SHLOKAS`
Use `\n` for a line break between the two halves.
```json
{"sa": "अग्रतो नारसिंहश्च …\nपृष्ठतो …", "en": "English meaning", "kn": "ಕನ್ನಡ ಅರ್ಥ", "src": "Source of the verse"}
```

### Add a sentence for the sentence builder — `SENTENCES`
`ans` is the set of correct words (any order is accepted). `extra` holds wrong-but-tempting words.
```json
{"en": "The girl sees the moon.", "kn": "ಹುಡುಗಿ ಚಂದ್ರನನ್ನು ನೋಡುತ್ತಾಳೆ.", "ans": ["बालिका", "चन्द्रं", "पश्यति"], "extra": ["चन्द्रः", "पश्यामि", "बालिकाम्"]}
```

### Add a dialogue — `DIALOGUES`
Each line is `["A" or "B", Sanskrit, English, Kannada]`. **B is the learner**; those lines become the practice questions.
```json
{"t": "विवाहे", "en": "At a wedding", "kn": "ಮದುವೆಯಲ್ಲಿ", "l": [
  ["A", "नमस्कारः।", "Hello.", "ನಮಸ್ಕಾರ."],
  ["B", "नमस्कारः। कथम् अस्ति भवान्?", "Hello. How are you?", "ನಮಸ್ಕಾರ. ಹೇಗಿದ್ದೀರಿ?"]
]}
```

### Add a story — `STORIES`
- `s` holds the sentences, each `[Sanskrit, English, Kannada]`.
- `moral` is `[Sanskrit, English, Kannada]`.
- `lvl` is the difficulty, 1–3.
- `g` is the glossary shown when a word is tapped: `"word": ["analysis", "English", "Kannada"]`. Words already in `COMMON_G` (एकः, सः, आसीत्…) don't need repeating.
```json
{"t": "कथा-नाम", "en": "Story title", "kn": "ಕಥೆಯ ಹೆಸರು", "src": "Pañcatantra, simplified", "lvl": 1,
 "s": [["वाक्यम्।", "Sentence.", "ವಾಕ್ಯ."]],
 "moral": ["नीतिः।", "Moral.", "ನೀತಿ."],
 "g": {"वाक्यम्": ["वाक्य · प्रथमा", "sentence", "ವಾಕ್ಯ"]}}
```

### Add verb roots or noun tables
These are generated by a grammar engine, not typed by hand. To add more, regenerate the tables with the grammar engine and update this file.

### Correct a mistake
Find the wrong text, fix it, raise `version`, commit. Phones get the fix on their next update.

## Rules of thumb
- Keep the quotes `"` around every piece of text.
- Don't use the characters `<` `>` or `` ` ``.
- Always raise `version`.
- Larger edits are easier on a computer. On github.com, press `.` while viewing the repository to open a full editor.
